# Графический редактор

Векторный графический редактор на Python с использованием PySide6 (Qt6 / QGraphicsView).

## Возможности

- **Фигуры:** точка, отрезок, луч, бесконечная прямая, прямоугольник, эллипс, многоугольник, ломаная, дуга, текст, кривая Безье
- **Выделение и трансформация:** выделение одиночное и рамкой, перемещение, маркеры преобразования
- **Группировка:** группировка и разгруппировка фигур
- **Undo / Redo:** полная поддержка отмены и повторения всех операций через `QUndoStack`
- **Буфер обмена:** копирование, вырезание, вставка и дублирование фигур
- **Z-Order:** перемещение фигур на передний / задний план
- **Экспорт:** в PNG (растр) и SVG (вектор)
- **Сетка:** настраиваемая двухуровневая сетка с привязкой (snap-to-grid)
- **Масштабирование:** колёсико мыши (с `Ctrl`) или кнопки меню; диапазон 5 % – 5000 %
- **Панорамирование:** перетаскивание холста при отключённом инструменте рисования
- **Автосохранение:** периодическое сохранение при изменении с восстановлением при запуске
- **Панель свойств:** редактирование цвета пера, кисти, толщины и поворота
- **Панель истории:** список всех фигур с возможностью выбора и удаления
- **Горячие клавиши:** полный набор для основных операций

## Установка

### Требования

- Python 3.9+
- PySide6

### Установка зависимостей

```bash
pip install -r requirements.txt
```

или:

```bash
pip install PySide6
```

### Запуск

```bash
python main.py
```

## Использование

### Инструменты

| Инструмент | Описание | Горячая клавиша |
|---|---|---|
| Выделение | Выделение и перемещение фигур | `V` |
| Точка | Создание точки | `P` |
| Отрезок | Создание отрезка двумя кликами | `L` |
| Луч | Создание луча (начало + направление) | `R` |
| Прямая | Создание бесконечной прямой | `I` |
| Прямоугольник | Создание прямоугольника | `Q` |
| Эллипс | Создание эллипса | `E` |
| Многоугольник | Замкнутый полигон (≥ 3 вершин) | `G` |
| Ломаная | Незамкнутая полилиния (≥ 2 вершин) | `Y` |
| Дуга | Создание дуги эллипса | `A` |
| Текст | Добавление текстовой надписи | `T` |
| Безье | Кривая Безье (2 управляющие точки) | `B` |

> **Примечание:** При рисовании с зажатым `Shift` осуществляется привязка углов к 0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+N` | Новый проект |
| `Ctrl+O` | Открыть проект |
| `Ctrl+S` | Сохранить |
| `Ctrl+Shift+S` | Сохранить как... |
| `Ctrl+Z` | Отменить |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Повторить |
| `Ctrl+C` | Копировать |
| `Ctrl+X` | Вырезать |
| `Ctrl+V` | Вставить |
| `Ctrl+D` | Дублировать |
| `Ctrl+A` | Выделить всё |
| `Delete` | Удалить |
| `Escape` | Снять выделение |
| `Ctrl+=` / `Ctrl+0` | Приблизить / Сбросить масштаб |
| `Ctrl+-` | Отдалить |
| `Ctrl+Shift+P` | Экспорт в PNG |
| `Ctrl+Shift+G` | Экспорт в SVG |

### Файлы

- **Проект:** расширение `.gproj` — JSON-файл с описанием фигур
- **Настройки:** `app_settings.json` — параметры приложения (сетка, цвета, поведение)
- **Экспорт PNG:** растровое изображение с белым фоном
- **Экспорт SVG:** векторное изображение

#### Формат проекта (.gproj)

```json
{
  "version": "1.0",
  "shapes": [
    {
      "id": 0,
      "type": "rectangle",
      "x": 100,
      "y": 100,
      "width": 200,
      "height": 150,
      "pen_color": [0, 0, 0],
      "pen_width": 2.0,
      "brush_color": [255, 255, 255],
      "rotation": 0,
      "group_id": null,
      "selected": false
    }
  ]
}
```

## Архитектура

Программа построена по модульному принципу:

- **`MainWindow`** — центральный оркестратор, координирующий работу всех подмодулей
- **`ShapeManager`** — управление коллекцией фигур, выделение, группировка, сигналы изменений
- **`ToolManager`** — активный инструмент, создание и обновление временных фигур
- **`ShapeRegistry`** — единая фабрика для создания фигур по типу (стратегия регистрации)
- **`FileManager`** — сериализация проектов в JSON, валидация, экспорт в PNG/SVG
- **`GraphicsCanvas`** — визуальный холст с сеткой, масштабированием и панорамированием
- **`QUndoStack`** — стандартный механизм отмены/повтора операций Qt
