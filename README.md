# Графический редактор

**Версия 1.0.2**

Векторный графический редактор на Python с использованием PySide6 (Qt6 / QGraphicsView).

## Возможности

- **Фигуры:** точка, отрезок, луч, бесконечная прямая, прямоугольник, эллипс, многоугольник, ломаная, дуга, текст, треугольник (равносторонний, равнобедренный, прямоугольный, тупоугольный), параллелограмм, трапеция (равнобедренная, произвольная), угол
- **Поворот:** вращение фигур вокруг центра через панель свойств (применяется при отрисовке)
- **Выделение и трансформация:** выделение одиночное и рамкой, перемещение, маркеры преобразования (8 ручек для эллипса, 4 вершины для полигонов)
- **Ресайз с пропорциями:** зажатие `Shift` при перетаскивании ручки сохраняет пропорции
- **Курсоры:** разные курсоры для разных ручек (диагональ, вертикаль, горизонталь)
- **Группировка:** группировка и разгруппировка фигур
- **Undo / Redo:** полная поддержка отмены и повторения всех операций через `QUndoStack`
- **Буфер обмена:** копирование, вырезание, вставка и дублирование фигур
- **Z-Order:** перемещение фигур на передний / задний план
- **Экспорт:** в PNG (растр) и SVG (вектор) с выбором области (все фигуры / выделенные / видимая область)
- **Сетка:** настраиваемая двухуровневая сетка с привязкой (snap-to-grid)
- **Масштабирование:** колёсико мыши (с `Ctrl`) или кнопки меню; диапазон 5 % – 5000 %
- **Панорамирование:** перетаскивание холста при отключённом инструменте рисования
- **Автосохранение:** периодическое сохранение при изменении с восстановлением при запуске
- **Автообновления:** автоматическая проверка обновлений через GitHub API
- **Настройки по умолчанию:** меню «Настройки» → «Параметры по умолчанию» — цвет контура, цвет заливки, толщина линии для новых фигур (сохраняются в `app_settings.json`)
- **Панель свойств:** редактирование координат, размеров, цвета пера, кисти, толщины и поворота
- **Панель истории:** список всех фигур с возможностью выбора и удаления
- **Тесты:** 650+ unit-тестов (pytest) для фигур, менеджеров, сериализации, валидации и настроек
- **Горячие клавиши:** полный набор для основных операций

## Установка

### Требования

- Python 3.12
- PySide6 >= 6.6.0

### Установка зависимостей

```bash
pip install -r requirements.txt
```

или:

```bash
pip install PySide6
```

### Запуск

```bash
python main.py
```

## Использование

### Инструменты

| Инструмент | Описание | Горячая клавиша |
|---|---|---|
| Выделение | Выделение и перемещение фигур | `V` |
| Move | Перемещение без рисования | `M` |
| Точка | Создание точки | `P` |
| Отрезок | Создание отрезка двумя кликами | `L` |
| Луч | Создание луча (начало + направление) | `R` |
| Прямая | Создание бесконечной прямой | `I` |
| Прямоугольник | Создание прямоугольника | `Q` |
| Эллипс | Создание эллипса | `E` |
| Дуга | Создание дуги эллипса (через диалог) | `A` |
| Многоугольник | Замкнутый полигон (≥ 3 вершин) | `G` |
| Ломаная | Незамкнутая полилиния (≥ 2 вершин) | `Y` |
| Текст | Добавление текстовой надписи | `T` |
| Треугольник | Выбор типа треугольника (диалог) | `8` |
| Параллелограмм | Параллелограмм (ввод сторон и угла) | `9` |
| Трапеция равнобедренная | Равнобедренная трапеция | `0` |
| Трапеция произвольная | Произвольная трапеция | `U` |
| Угол | Угол (две стороны из общей вершины) | `J` |

> **Примечание:** При рисовании с зажатым `Shift` осуществляется привязка углов к 0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°.

### Файлы

- **Проект:** расширение `.gproj` — JSON-файл с описанием фигур
- **Настройки:** `app_settings.json` — параметры приложения (сетка, цвета, поведение)
- **Экспорт PNG:** растровое изображение с белым фоном
- **Экспорт SVG:** векторное изображение

#### Формат проекта (.gproj)

```json
{
  "version": "1.0",
  "shapes": [
    {
      "id": 0,
      "type": "rectangle",
      "x": 100,
      "y": 100,
      "width": 200,
      "height": 150,
      "pen_color": [0, 0, 0],
      "pen_width": 2.0,
      "brush_color": [255, 255, 255],
      "rotation": 0,
      "group_id": null,
      "selected": false
    }
  ]
}
```

## Архитектура

Программа построена по модульному принципу:

- **`MainWindow`** — центральный оркестратор, координирующий работу всех подмодулей
- **`ShapeManager`** — управление коллекцией фигур, выделение, группировка, сигналы изменений
- **`ToolManager`** — активный инструмент, создание и обновление временных фигур с параметрами из настроек
- **`ShapeRegistry`** — единая фабрика для создания фигур по типу (стратегия регистрации)
- **`FileManager`** — сериализация проектов в JSON, валидация, экспорт в PNG/SVG
- **`GraphicsCanvas`** — визуальный холст с сеткой, масштабированием и панорамированием
- **`AutoSaver`** — периодическое автосохранение проекта (QTimer + QUndoStack.cleanChanged)
- **`ShapeParamDialog`** — диалоги для ввода дополнительных параметров фигур (треугольник, параллелограмм, трапеция, угол)
- **`SettingsDialog`** — диалог настроек по умолчанию для новых фигур (цвет контура, заливка, толщина линии)
- **`QUndoStack`** — стандартный механизм отмены/повтора операций Qt

## Тестирование

Проект содержит 650+ unit-тестов, покрывающих все фигуры, менеджеры, сериализацию, валидацию, повороты и настройки.

### Запуск тестов

```bash
# Через helper-скрипт
python3 run_tests.py

# Или напрямую через pytest
pytest tests/ -v
```

Тесты запускаются в offscreen-режиме Qt (без графического интерфейса).
