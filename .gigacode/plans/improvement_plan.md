# План улучшений проекта «Графический редактор»

## 1. Критические баги и надёжность

### 1.1. Исправить `MoveShapesCommand._get_position` — хак с `__import__`

**Файл:** `manager/undo_commands.py`
**Проблема:** Динамический `__import__` для проверки типа фигуры — не работает корректно и нарушает принципы ООП.
**Решение:** Использовать `isinstance(shape, PolygonShape)` после нормального импорта, либо проверить `shape.shape_type.value`.

### 1.2. Исправить `1.svg` — расширение не соответствует формату

**Файл:** `1.svg`
**Проблема:** Содержит JSON-данные, но расширение `.svg`. Это вводит в заблуждение и ломает автоопределение формата.
**Решение:** Переименовать в `1.json` (это проект, а не SVG).

### 1.3. Дублирование логики экспорта SVG

**Файл:** `fileio/file_manager.py`
**Проблема:** `export_svg` генерирует SVG вручную строками, а `GraphicsCanvas.export_to_svg` использует `QSvgGenerator`. Два разных результата.
**Решение:** Оставить один путь — `QSvgGenerator` (качественнее, поддерживает трансформации). Убрать ручную генерацию.

### 1.4. Отсутствие валидации входных данных при загрузке

**Файл:** `fileio/file_manager.py`
**Проблема:** При загрузке JSON нет проверки обязательных полей (`x`, `y`, `x1`, `y1` и т.д.) — может вызвать `KeyError`.
**Решение:** Добавить валидацию обязательных полей с понятными сообщениями об ошибках.
**Статус: ✅ ВЫПОЛНЕНО** — создан `fileio/validators.py` с валидацией всех типов фигур, проверкой числовых полей, цветов, вершин, размера файла (макс. 10 МБ), количества фигур (макс. 10 000).

## 2. Архитектура и качество кода

### 2.1. Убрать дублирование фабрик

**Файл:** `fileio/file_manager.py`, `manager/shape_manager.py`, `manager/undo_commands.py`
**Проблема:** Фабрики фигур дублируются в 3 местах (импорт + словарь映射).
**Решение:** Создать единый модуль `shapes/registry.py` с глобальной регистрацией. `FileManager` и `ShapeManager` берут отовсюду.
**Статус: ✅ ВЫПОЛНЕНО** — `shapes/registry.py` существует, `__import__` заменён на нормальные импорты в `_cache_shape_classes`.

### 2.2. Вынести `ShapeSceneItem` в отдельный ответственность

**Файл:** `ui/scene_items.py`
**Проблема:** `ShapeSceneItem` не обрабатывает мышь, вся логика — в `GraphicsCanvas`. Это нарушает принцип единственной ответственности QGraphicsItem.
**Решение:** Либо включить обработку мыши в `ShapeSceneItem`, либо убрать его и работать напрямую с фигурами.

### 2.3. Унифицировать события мыши

**Файл:** `canvas/graphics_canvas.py`, `ui/window_events.py`
**Проблема:** Сигналы мыши продублированы в Canvas и фильтруются в `MainWindow.eventFilter` (Ctrl+scroll).
**Решение:** Перенести масштабирование в коллбэк `wheelEvent` Canvas, убрать `eventFilter` из MainWindow.

### 2.4. Убрать прямые обращения к приватным атрибутам

**Файл:** `manager/shape_manager.py` (paste_from_clipboard)
**Проблема:** `shape._x`, `shape._x1`, `shape._vertices` — прямое обращение к приватным полям разных фигур.
**Решение:** Добавить универсальный метод `shape.offset(dx, dy)` в `BaseShape`, который знает свои координаты.

### 2.5. Убрать `TYPE_CHECKING` циклические импорты

**Файл:** `manager/undo_commands.py`
**Проблема:** Импорт классов фигур внутри методов — работает, но ухудшает читаемость и IDE-подсказки.
**Решение:** Вынести все фабрики в `shapes/registry.py` и импортировать оттуда.

## 3. Функциональные улучшения

### 3.1. Добавить автосохранение (autosave)

**Новый файл:** `manager/autosaver.py`
**Описание:** Периодическое сохранение проекта в временный файл. При краше — возможность восстановления.
**Реализация:** `QTimer` → `FileManager.save_json` в `.autosave.json`.

### 3.2. Добавить поддержку горячих клавиш (accelerator)

**Файл:** `ui/window_actions.py`
**Описание:** Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S, Ctrl+Z, Ctrl+Shift+Z, Ctrl+C, Ctrl+V, Ctrl+X, Delete, Escape, G, S, L, R, P, E, Ctrl++/Ctrl+-.
**Реализация:** `QShortcut` для каждой комбинации.

### 3.3. Добавить историю изменений для Undo-стека

**Файл:** `manager/undo_stack.py`
**Описание:** Отображение названий команд в HistoryPanel (сейчас панель показывает только фигуры, а не действия).
**Реализация:** Подключить `QUndoStack` сигналы `indexChanged` к панели.

### 3.4. Добавить инструменты: дуга, текст, сплайн

**Новые файлы:** `shapes/arc_shape.py`, `shapes/text_shape.py`, `shapes/bezier_shape.py`
**Описание:** Расширение набора инструментов.
**Реализация:** Добавить новые классы фигур с фабрикой.
**Статус: ✅ ВЫПОЛНЕНО** — реализованы TextShape (текстовая надпись с настройкой размера шрифта) и BezierShape (кубическая кривая Безье с 4 контрольными точками). Все фигуры зарегистрированы в ShapeRegistry, добавлены кнопки и горячие клавиши (T для текста, B для сплайна).

### 3.5. Добавить удаление фигур через HistoryPanel

**Файл:** `ui/history_panel.py`
**Проблема:** `_on_history_shape_deleted` вызывает `selection_changed.emit()`, но не удаляет фигуру.
**Решение:** Вызвать `manager.delete_shape_by_id(shape_id)`.

### 3.6. Добавить Undo для операций с группами

**Файл:** `manager/undo_commands.py`
**Проблема:** `group_selected()` и `ungroup_selected()` не имеют Undo-команд.
**Решение:** Добавить `GroupCommand` и `UngroupCommand`.
