## [0.5.0] — 2026-09-16

### Добавлено
- **(1.4)** Валидация загружаемых файлов: `fileio/validators.py` с проверкой размера (10 МБ), структуры JSON, количества фигур (10 000)
- **(3.4)** Инструменты: TextShape (текстовая надпись), диалог ввода текста
- **(3.5)** Удаление фигур через HistoryPanel
- **(3.6)** Undo-команды для группировки/разгруппировки: `GroupCommand`, `UngroupCommand`
- **(4.1)** Контекстное меню на холсте (ПКМ): Копировать, Вставить, Вырезать, Удалить, Дублировать, На передний план, На задний план
- **(4.2)** Поля X, Y, Ш, В в панели свойств для прямоугольных фигур
- **(4.3)** Подтверждение сохранения при закрытии окна
- **(4.4)** Тултипы к кнопкам инструментов, строка подсказок в статусбаре
- **(6.1)** Полная документация в `README.md`
- **(7.1)** Кэширование сетки в `QPixmap` для производительности
- 7 параметрических фигур: равнобедренный/прямоугольный/разносторонний треугольники, параллелограмм, равнобедренная/произвольная трапеция
- Инструменты: точка, отрезок, луч, прямая, прямоугольник, эллипс, многоугольник, ломаная, дуга, текст
- Автосохранение проекта с восстановлением при запуске
- Горячие клавиши для всех основных операций (Ctrl+N/O/S, Z/Y, C/V/X, Delete, Escape и др.)
- Undo/redo для всех операций: добавление, удаление, перемещение, изменение свойств, группировка
- Экспорт в PNG и SVG

### Исправлено
- **(1.1)** Убран динамический `__import__` в `undo_commands.py`
- **(1.3)** Убрана ручная генерация SVG, оставлен `QSvgGenerator`
- **(2.1)** Убрано дублирование фабрик фигур — создан `shapes/registry.py`
- **(2.3)** Масштабирование перенесено в `wheelEvent` Canvas
- **(2.4)** Добавлен универсальный метод `shape.offset(dx, dy)` в `BaseShape`
- **(2.5)** Нормальные импорты вместо `TYPE_CHECKING` циклических
- Segfault на Wayland — принудительное использование XCB
- Segfault при рисовании отрезка — защита от NaN/inf координат
- Segfault при рисовании второго отрезка — переписан `sync_scene_with_manager`
- Сетка рисовалась кусками — восстановлено корректное рисование
- ARC и BEZIER не рисовались — исправлена отрисовка
- Текст и сплайн не рисовались — исправлен `finish_drawing`
- Точка рисовалась не в месте клика — исправлено смещение
- Дуга и сплайн рисовались неправильно — исправлена геометрия
- Порядок вершин фигур — унифицирована нумерация вершин по часовой стрелке
- PropertyPanel: показ координат для дуги
- Переработка дуги: параметрический диалог, исправления свойств и drag
- Произвольная трапеция: добавление + исправление undo/redo и экспорта

### Удалено
- Кривые Безье (BezierShape) — удалены из программы

## [0.4.0] — 2026-09-xx

### Добавлено
- Базовая архитектура с разделением на модули: `shapes/`, `canvas/`, `manager/`, `ui/`, `fileio/`, `tools/`, `settings/`
- `ShapeSceneItem` — QGraphicsItem-обёртка для отрисовки фигур
- `GraphicsCanvas` — холст с сеткой, зумом, панорамированием
- `ShapeManager` — управление коллекцией фигур, выделение, сигналы
- `QUndoStack` — undo/redo инфраструктура
- `FileManager` — сохранение/загрузка `.gproj`, экспорт PNG/SVG
- `ToolManager` — менеджмент активных инструментов рисования
- Панель свойств, панель истории, статусбар
- Меню и тулбары с инструментами
